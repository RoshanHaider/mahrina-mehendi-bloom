🌸 Mahrina Mehendi Bloom

Mahrina Mehendi Bloom is a modern and responsive web application designed to showcase beautiful mehendi (henna) designs and services in an elegant and user-friendly way. The project focuses on providing a visually appealing experience with smooth navigation, attractive layouts, and mobile-friendly responsiveness.

✨ Features

Elegant and modern user interface

Responsive design for desktop, tablet, and mobile devices

Beautiful presentation of mehendi designs and services

Smooth navigation and interactive user experience

Fast-loading and optimized performance

Clean and organized code structure


🛠️ Technologies Used

HTML5

CSS3

JavaScript

React.js

Vercel Deployment


🎯 Project Goal

The goal of this project is to create a professional online presence for a mehendi artist or business, allowing visitors to explore designs, learn about services, and enjoy a seamless browsing experience.
